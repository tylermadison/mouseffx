- 1.x: `server-only` was added as one more dependency, for `src/lib/docs/excerpt.ts`. `src/mdx.d.ts` was added because TypeScript 6 does not include `@types/mdx` automatically. `typecheck` now runs `next typegen` first, because the generated route types must know the new routes.
- 3.3: First version failed in the browser. `backdrop-filter` on the content panel makes the panel the containing block for `position: fixed`, so the `#fx` layer covered the text. Corrected with a portal to `document.body` (design Decision 7).
- 4.2 (worst case: pure white behind the panel, blend `rgb(35, 35, 38)`): body text 14.0:1, `--docs-dim` 6.6:1, links 11.2:1, lede 11.6:1, technology label 8.6:1. On the opaque code background: table text 17.8:1, table head 8.4:1, code comment 6.6:1, keyword 8.1:1, punctuation 9.3:1, inline code 14.0:1. The old `--dim` would be 3.5:1 and is not used for text.
- 4.3: The constants are shown as cards, not as a table (design Decision 4). MDX has no table syntax without a plugin, so a `Table` component was added for data tables.
- 5.1: 47 regions in the eight effect modules. The diff of `src/lib/mousefx/effects` has marker lines only.
- 5.3 (production build, viewport 1504×1519, dpr 2): gravity-well same, fluid same, matrix same, orbits same, tendrils same, nebula same, ascii same, warp same. All 60 fps. Fixed counts are equal to the earlier values (262,144 / 3,200 / 14,000). The other counts depend on the viewport. No console error or warning, so the shaders with markers inside GLSL strings compile.
- 6.x: `tendrils` was written first as the model page. The other seven pages were written in parallel by seven agents with one authoring guide, and each was checked (marker-only diff, `check:docs`, render, static HTML). The pages are longer than planned (2,200 to 2,800 words against 1,400 for the model page), because the topic lists were long.
